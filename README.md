# mvp-electric.com
Website for mvp-electric.com

The live site runs on WordPress + Elementor + Yoast. This repo holds the SEO plan, ready-to-paste
code and copy, and design mockups for the site.

| File | What it is |
|---|---|
| `seo/AUDIT-AND-PLAN.md` | **Start here.** Problems on the live site, Google Business Profile and AI-search steps, 90-day plan |
| `seo/schema-electrician.html` | Local-business (Electrician) structured data. Paste in via the WPCode plugin |
| `seo/llms.txt` | Upload to the site root (mvp-electric.com/llms.txt) for AI assistants |
| `seo/page-copy/titles-and-meta.md` | SEO titles, meta descriptions and H1s for every page |
| `seo/page-copy/homepage.md` | Rewritten homepage copy (real reviews, service area, FAQ) |
| `seo/page-copy/service-area-pages.md` | New Washington / Clackamas / Multnomah county pages |
| `seo/page-copy/new-service-pages.md` | New Panel Upgrades and Generator Installation pages |
| `design/homepage-options.html` | 3 homepage redesign options (open in a browser, switch with the buttons at the top) |
